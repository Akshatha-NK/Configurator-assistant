#Oracle Configurator AI Chatbot

An AI-powered chatbot built with Streamlit that allows Oracle Configurator teams to upload reports and ask natural language questions about their configuration data.

##Built With
-Python
-Streamlit
-OpenAI API
-Oracle Configurator domain knowledge

##Features
-Upload Configuration reports
-Ask questions in plainn English anything related to oracle configurator developer
-Get instanct answers without SQL or UI navigation
